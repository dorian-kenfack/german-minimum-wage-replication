## Restricted source data

The working-hours dataset was constructed using district-level data from the
Arbeitskreis Erwerbstätigenrechnung der Länder. The original source files are
not included in this repository because redistribution is restricted.

The analysis uses data on employed persons and total annual hours worked for
2013–2016. These data were aggregated from the Kreis level to labor-market
regions (AMRs) using the BBSR 2017 regional mapping.

The resulting AMR-level dataset used in the analysis is provided in
`data/final/AMR_Working_Hours_2013_2016.csv`.
